## 2. Project Overview
Aroma Heaven is a responsive, user-friendly website for a fictional coffee shop based in Polokwane, Limpopo. The project was created for the WEDE POE.

The website aims to establish an online presence for the coffee shop, allowing customers to view the menu, learn about the business story, find the location, and contact the shop. The site is built using only HTML5 and CSS3 and follows modern web standards for responsiveness, accessibility, and SEO.

This README will be updated throughout Part 1, Part 2, and Part 3 of the POE.

## 3. Website Goals and Objectives
**Primary Goal:** To create a professional online platform that attracts customers and increases foot traffic to the physical store.

**Objectives:**
- Provide clear information about products, prices, and location
- Ensure the website is fully responsive on mobile (375px), tablet (768px), and desktop (1024px+)
- Use semantic HTML5 for better SEO and accessibility
- Improve user experience with intuitive navigation and fast loading
- Establish brand identity for Aroma Heaven - "Where Every Sip Feels Like Heaven"

## 4. Key Features and Functionality
- **4 Linked Pages:** Home (index.html), Menu, About Us, Contact
- **Responsive Design:**
    - CSS Grid and Flexbox for layout
    - Media Queries: 480px (mobile), 768px (tablet), 1024px (desktop)
    - Relative units: rem, em, %, vw/vh
- **Navigation:** Sticky navbar with hamburger menu for mobile
- **Visual Effects:** Hover, focus, and active states on buttons and cards
- **Images:** Optimized, responsive images using `width: 100%`
- **Contact Form:** HTML5 form with required validation
- **SEO Ready:** Meta viewport, descriptive titles, alt attributes
