# Aroma Heaven Coffee Shop - WEDE POE Part 1 & 2
Responsive website for Aroma Heaven in Polokwane. Built with HTML5 + CSS3.
Features: Product Codes PRD001-PRD006, Enquiry Code ENQ-XXXX-2026 auto-generated, Nav hover colour (brown background on ABOUT shows clickable).
Responsive: Flexbox, Grid, Media Queries 480px/768px/1024px, rem/em/%.
Tested in Chrome DevTools - Mobile 375px 1 column, Tablet 768px 2 column, Desktop 3 column.
